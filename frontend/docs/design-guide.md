# Webtop Design Guide

`korellas/webtop` 프론트엔드의 시각 체계 정본. 값이 갈릴 때 이 문서가 이깁니다.
토큰 원본은 `frontend/src/app.css`이며, 이 문서와 그 파일은 항상 함께 갱신합니다.

시각 레퍼런스: `Webtop Design Guide.dc.html` (브라우저로 열면 §13.4에 전부 적용된 화면)

---

## 0. 원칙

판단이 갈릴 때 이 순서로 결정합니다.

1. **숫자가 주인공.** 크롬은 절대 데이터보다 크거나 밝지 않습니다. 라벨은 `text-secondary`, 값은 `text-primary` + 굵기 + `tabular-nums`.
2. **지표 = 색.** 색은 장식이 아니라 식별자입니다. 색↔지표 매핑은 테마와 화면을 넘어 불변입니다.
3. **레이아웃은 고정.** 패널을 열어도 차트 상단선은 움직이지 않습니다. 오버레이는 화면을 덮되 대체하지 않습니다.
4. **모션은 상태 전달용.** 실시간 데이터 위에서 애니메이션은 노이즈입니다.

## 1. 컬러

값은 `tokens.css`가 정본입니다. 이 절은 규칙만 서술합니다.

### 1.1 두 계열만 존재

| 계열 | 테마 반응 | 용도 |
| --- | --- | --- |
| 크롬 | 테마별로 뒤집힘 | 서피스 5단, 보더 2단, 텍스트 3단, 차트 그리드/축 |
| 데이터 | hue 고정, 명도만 한 단계 조정 | 지표 식별 |

### 1.2 인터랙션 색은 없습니다

**활성 상태에 액센트를 쓰지 않습니다.** 탭·pill·토글의 활성은 `bg-hover` + `text-primary` + `font-weight 600`.

개정 전에는 활성 탭과 CPU 선이 둘 다 `blue-500`이었습니다 — 하나는 "네가 누른 것", 하나는 "기계 상태"인데 색이 같았습니다. 파랑은 이제 **데이터(CPU)와 텍스트 링크 전용**입니다.

### 1.3 카드당 hue 하나

카드 안의 시리즈는 새 hue가 아니라 **명도 3단(base / light / dim 45%) + 선 패턴**으로 구분합니다.

예외는 CPU/GPU 카드 하나뿐 — GPU는 CPU의 분해값이 아니라 별개 서브시스템이므로 hue를 따로 갖습니다.

`fan`만 hue가 아니라 중립(slate)입니다. 온도와 같은 종류의 양이 아니면서 같은 축에 얹혀 있으므로, 종속성을 형태와 색으로 함께 알립니다.

### 1.4 DO / DON'T

**DO**
- 색은 `var(--color-*)`로만 참조 — hex 하드코딩 금지
- 상태 색은 텍스트와 항상 병기 (색만으로 의미 전달 금지)
- 액센트 배경 위 전경은 `--color-accent-fg` = `#ffffff` 고정

**DON'T**
- 새 지표에 새 hue 추가 — 기존 계열의 명도 변형 사용
- 액센트를 배경 대면적에 사용 — 선·점에만
- 그라디언트 채우기를 2개 이상 겹치기 — 시리즈 판독을 방해
- 상태색(`danger`/`warning`/`ok`)을 차트 선·면에 사용 — 텍스트와 1px 보더에만

## 2. 타이포그래피

### 2.1 서체

| 역할 | 서체 |
| --- | --- |
| 라벨·문장 | IBM Plex Sans (한글 폴백 IBM Plex Sans KR) |
| **모든 수치와 식별자** | IBM Plex Mono |

Mono가 숫자를 받는 이유: 화면의 절반이 숫자이고 그 숫자가 초당 바뀝니다. 폭이 변하면 값이 떨립니다. 그리고 `0/O`, `1/l/I`, `5/S`, `8/B`가 확실히 다른 것은 포트 번호와 PID를 읽는 앱에서 기능입니다.

전부 OFL 1.1, 무료·상업적 사용 가능. **셀프호스팅 필수** — LAN 로컬 도구이므로 CDN을 쓰면 인터넷이 끊긴 상태에서 서체가 깨집니다. woff2 4개(Sans 400/600, Mono 400/600 · 라틴 서브셋 ≈120KB)를 `frontend/public/fonts/`에 두면 `build.rs`가 바이너리에 포함합니다.

### 2.2 스케일 — 5단

| 토큰 | px / weight | Family | 용도 |
| --- | --- | --- | --- |
| `metric-hero` | 20 / 700 | Mono | 차트 카드 주값 (카드당 1개) |
| `value-lg` | 15 / 600 | Mono | 칩 주값, 오버레이 제목 |
| `value` | 13 / 500 | Mono | 범례 보조값, 테이블 수치 |
| `label` | 13 / 500 | Sans | 카드 제목, 내비 탭, 컬럼 헤더 |
| `caption` | 11 / 400 | Mono | 축 라벨, 칩 라벨, 단위, 상태바 |

**9px 토큰은 삭제되었습니다.** 판독해야 하는 모든 문자열은 11px 이상입니다. 단위 접미사도 caption 11px + `text-muted`로 처리합니다.

숫자에는 예외 없이 `tabular-nums`.

## 3. 간격 · 그리드 · 반경

4px 기반. 대시보드는 높이가 희소 자원이므로 24px 이상은 문서·오버레이 내부에만 씁니다.

| 값 | 용도 |
| --- | --- |
| 2 | 아이콘–값 붙임 |
| 4 | 내비 탭 간격 |
| 6 | 칩 스트립 gap |
| 8 | 칩 세로 패딩 |
| 12 | 칩 가로 패딩, 상태바 |
| **16** | 오버레이 인셋 — **기준선** |
| 24 | 드로어 섹션 |

### 반경

| 값 | 용도 |
| --- | --- |
| 6px | 크롬 컨트롤 (pill, 토글, 입력, 내비 탭) |
| 8px | 콘텐츠 카드 (칩, 차트 그리드) |
| 12px | 오버레이 패널 |
| 999px | 연결 인디케이터, 링 게이지 |

개정 전에는 상태바 안에서 내비 탭 8px / 타임스케일 pill 6px / 배지 4px가 섞여 있었습니다. **크롬 컨트롤은 6px 하나**로 통일하고 8px는 콘텐츠 카드 전용으로 예약합니다.

### 고정 치수

| 요소 | 치수 |
| --- | --- |
| 상태바 | h 40px · 모든 폭에서 동일 |
| Summary chip | min-w **144px** · 게이지 30px (stroke 2.5) |
| 오버레이 | `min(92vw, 800px)` × `min(74vh, 620px)` |
| 터치 타깃 | 최소 28px (WCAG 2.2 AA 2.5.8) |

칩의 144px는 협상 대상이 아닙니다 — 가장 긴 sub-line(`prev 18.43 kWh`)이 86px을 요구하고, 게이지 30 + gap 8 + 패딩 24를 빼면 그게 남는 최소값입니다.

### 차트 그리드

3행 × 2열. 셀 사이는 **1px 보더만** — gap도 개별 카드 그림자도 없습니다. 6개 플롯이 최대 면적을 갖고 공유된 X축이 시각적으로 정렬됩니다.

## 4. 차트

배정표는 `series.json`이 정본입니다. 이 절은 규칙만 서술합니다.

### 4.1 판독은 하나

같은 숫자를 두 번 보여주지 않습니다.

| 위계 | 스타일 | 내용 |
| --- | --- | --- |
| tier 1 | 20px mono 700, 시리즈 색 | 카드의 주값 — 카드당 정확히 1개 |
| tier 2 | 13px mono 500 | 보조 주계열 (GPU, Swap, Write, Up) |
| tier 3 | 11px mono 400 `text-muted`, 우측 정렬 | 파생값 · 피크 · trough |

**삭제되는 것: 끝단 value pill, 플롯 위 peak/trough 배지.** 둘 다 범례가 이미 가진 숫자를 반복하며 선을 가립니다. 피크는 현재값과 다른 *종류*의 정보이므로 tier 3 그룹에 세로 구분선으로 분리합니다.

피크의 *시점*을 꼭 보여야 한다면 플롯 상단 16px를 배지 전용 레일로 예약하고 X만 데이터에 맞춥니다 — 세로 충돌이 구조적으로 불가능해집니다. 예비안입니다.

### 4.2 시리즈 스타일 계약

| tier | stroke | pattern | fill | 카드당 최대 |
| --- | --- | --- | --- | --- |
| primary | 2px | solid | 그라디언트 28% → 0% | **1** |
| secondary | 1.5px | solid | 없음 | 1 |
| derived | 1px · 45% | 4-3 / 2-2 / 6-3 | 없음 | 2 |
| band | — | — | solid 12% | — |
| threshold | 1px | 6-4 | 없음 | 1 |

면적을 갖는 것은 primary 하나뿐입니다. 2개 이상은 진흙이 됩니다.

다운샘플 min/max 범위(band)는 점선 2줄이 아니라 **면**으로 그립니다.

### 4.3 축

- 눈금은 균등하게 (0 / 50 / 100 또는 사분위). 개정 전 35 / 70 / 100은 균등하지 않았습니다
- baseline(0)은 `border-strong`으로 강조, 나머지 그리드는 `chart-grid`
- 축 라벨은 caption 11px `text-secondary`
- **그리드라인은 SVG 안의 `<line>`으로** — 절대 위치 div로 얹으면 플롯과 어긋납니다

### 4.4 Temperature 카드 — 팬 곡선은 현재 축에 유지

CPU 온도(°C)와 팬(최대 RPM의 %)이 같은 0–100 축을 공유합니다. 축이 팬에 대해 애매한 것은 알려진 사실입니다.

**팬을 별도 트랙으로 분리하는 안은 검토 후 기각했습니다.** 6개 셀 중 하나가 구조적으로 달라지는데, 그건 원래 보조 Y축을 없앤 이유와 정확히 같은 문제입니다. 그리드 균질성이 축 순수성보다 우선합니다.

대신 구조를 건드리지 않는 두 가지를 지킵니다:

1. 팬은 항상 중립 slate 1px dashed 45%로 **종속적으로** 그려 "같은 종류의 양이 아님"을 형태로 알립니다
2. 실제 RPM은 범례와 툴팁만 소유합니다 — **축 눈금은 °C만 뜻합니다**

### 4.5 임계값

지표별 임계선을 1px dashed `warning`으로 그리고, 초과 시 **칩 보더만** `danger`/`warning`으로 바꿉니다. 배경 채우기·깜빡임은 금지입니다 — 실시간 화면에서 깜빡임은 정보가 아니라 방해입니다.

## 5. 컴포넌트

### Summary chip
게이지 + 라벨/값/보조값. 드릴다운 가능 여부는 hover·active 상태로만 드러냅니다.
- default: `bg-card` + `border`
- hover: `bg-hover` + `border-strong`
- active(드로어 열림): hover와 동일
- non-interactive(GPU, I/O): 상태 변화 없음
- 임계 초과: 보더만 상태색

### 차트 셀
제목 → tier1 → tier2 → tier3(우측). 제목행은 플롯 위에 겹쳐 얹혀 높이를 소비하지 않습니다.

### 내비 탭 / 세그먼트 컨트롤
활성 = `bg-hover` + `text-primary` + 600. 아이콘 15px(`NavIcon.tsx`)는 모든 폭에서 렌더, 라벨은 `sm` 이상.

### 테이블 (Services / Processes)
얼룩말 무늬 없음. 행 구분은 hover와 정렬된 `tabular-nums`가 담당합니다.

### 오버레이 패널
- 폭 하나: `min(92vw, 800px)`. 두 가지 폭은 두 개의 컴포넌트처럼 느껴집니다
- 배경 `bg-elevated` — 다크에서 뒤의 카드보다 **밝아야** 합니다
- 사방에 대시보드가 남아 보이는 것이 "임시"임을 알리는 유일한 신호입니다
- Esc로 닫힘, scrim 클릭으로 닫힘
- height: `fill`(Processes, 수백 행) / `hug`(Services, 매니페스트가 선언한 만큼)

### Services 헤더
down 서비스를 문장으로 나열하지 않습니다. `6 down · 6 not installed` 카운트 배지 하나 + 표에서 down을 정렬 우선으로 올립니다. 장문 danger 텍스트는 읽기 전에 무섭고, 읽으면 아래 표와 중복입니다.

## 6. 테마

테마는 크롬만 뒤집습니다. 지표 액센트는 hue를 유지하고 흰 배경 대비를 위해 한 단계 진해집니다 — 사용자가 배우는 색 매핑이 테마마다 달라지면 안 됩니다.

| | |
| --- | --- |
| **불변** | hue 매핑 · 레이아웃 · 치수 · 반경 · 모션 · `accent-fg` |
| **가변** | 서피스 5단 · 보더 2단 · 텍스트 3단 · 차트 그리드/축 · 액센트 한 단계 |

엘리베이션: **다크는 위로 갈수록 밝아지고, 라이트는 위로 갈수록 흰색에 가까워집니다.** 두 테마 모두 "높이 = 밝기".

시스템 연동은 light / auto / dark 3택. 폰(<640px)에서는 폭 부족으로 순환 버튼 1개로 접힙니다.

## 7. 모션

데이터는 초당 갱신됩니다. 그 위에서 움직이는 것은 **사용자가 일으킨 변화**뿐이어야 합니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `motion-enter` | 120ms `ease-out-expo` | 오버레이 등장 — 6px 상승 + 0.985 스케일. 슬라이드 아님 |
| `motion-state` | 150ms | hover / active / 탭 전환 |
| `motion-fade` | 500ms | 터치 판독값 hold-and-fade |
| — | **0ms** | 차트 선·숫자 갱신. 보간된 선은 존재하지 않은 값을 그립니다 |

transition 대상은 `background-color, border-color, transform`만. **`all` 금지.**

hover fade는 `<html data-hover-fading>` 속성으로 구동합니다 — React state로 하면 6개 차트가 제스처 중에 리렌더됩니다.

**`prefers-reduced-motion: reduce`에서 모든 animation/transition을 none으로.** 모든 모션은 장식이며 기능은 100% 유지됩니다.

## 8. 반응형

폭이 줄면 **축소하지 않고 제거**합니다. 축소는 판독 불가한 텍스트를 만들고, 제거는 남은 것을 온전하게 둡니다.

| 요소 | Phone <640 | Tablet 768+ | Desktop 1024+ |
| --- | --- | --- | --- |
| 차트 그리드 | 1열 세로 스크롤 · 셀 180px 고정 | 2×3, 높이 균등 | 동일 · 뷰포트 채움 |
| 칩 스트립 | 가로 스크롤 + 우측 24px 페이드 마스크 | 동일 | `flex-1`로 행 채움, 마스크 제거 |
| 내비 탭 | 아이콘만 | 아이콘 + 라벨 | 동일 |
| 머신 식별 | 제거 | 모델명만 | 전체 문자열 |
| 테마 컨트롤 | 순환 버튼 1개 | 3-way radiogroup | 동일 |
| 오버레이 | 92vw | 92vw | 800px |

### 필수 사항

- **`h-dvh` (100vh 금지).** 루트가 `overflow-hidden`이므로 100vh는 모바일에서 영구 클리핑을 만듭니다 — URL 바가 스크롤에 반응해서만 접히는데 스크롤할 것이 없습니다.
- **safe-area.** `viewport-fit=cover`를 요청했으므로 루트 4면에 `env(safe-area-inset-*)` 패딩이 필수입니다.
- **flex 축소 규칙.** 한 줄 안에서 압력이 걸리면 *식별 문자열*이 줄어들고 컨트롤은 줄지 않습니다 — 식별 span에 `min-w-0` + `truncate`, 컨트롤 그룹에 `shrink-0`.
- **모바일 앵커.** 폰에서 6개 셀 × 180px는 1080px 스크롤입니다. 칩 스트립 탭 → 해당 차트로 스크롤 연동.

## 9. 값 포맷

라운딩 규칙은 **한 곳**에만 있습니다.

```ts
/** 앱 전체 단일 규칙: 10 미만에서만 소수 1자리. */
export const formatPct = (v?: number) =>
  v == null || Number.isNaN(v) ? '—'
  : v < 10 ? `${v.toFixed(1)}%`
  : `${Math.round(v)}%`;
```

개정 전에는 칩이 `CPU 3%`, 같은 시점 범례가 `CPU 3.1%`였습니다. 두 곳에 규칙이 있었기 때문입니다. 로컬 `Math.round()`는 모두 제거합니다.

바이트 레이트 축 라벨은 5글자 제한(`formatRateTick`) — 축 거터가 38px이고 왼쪽부터 잘리므로, 넘치면 못생긴 라벨이 아니라 **틀린 라벨**이 나옵니다.

결측값은 `undefined`가 아니라 `null`로 — `undefined / divisor`는 `NaN`이고 SVG path를 통째로 깨뜨립니다. `null`은 `connectNulls`가 이어줍니다.

## 10. 접근성 하한

- 본문·라벨 대비 4.5:1, 큰 텍스트 3:1
- 터치 타깃 28px 이상
- 상태는 색 + 텍스트 병기
- 모든 모션은 `prefers-reduced-motion`에서 제거 가능
- 오버레이는 `role="dialog"` + `aria-label`, Esc 닫기
- 내비는 `aria-current`, 토글 그룹은 `role="radiogroup"` + `aria-checked`
